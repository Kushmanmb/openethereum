# Security Policy

## Supported Versions

Security fixes are applied to the latest release. We recommend always running the most recent stable version of OpenEthereum.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| older   | :x:                |

## Reporting a Vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

If you discover a security vulnerability in OpenEthereum, please report it responsibly by emailing:

**security@parity.io**

Please include the following information in your report:

- A description of the vulnerability and its potential impact
- Steps to reproduce the issue
- Any proof-of-concept or exploit code (if available)
- Your suggested fix (if any)

You will receive a response within 72 hours acknowledging receipt of your report. We will keep you informed of our progress as we work to address the issue.

Once the vulnerability is confirmed and a fix is prepared, we will:

1. Notify you before public disclosure
2. Credit you in the release notes (unless you prefer to remain anonymous)
3. Publish a security advisory

We kindly ask that you do not publicly disclose the vulnerability until we have had a reasonable amount of time to address it.

## Security Advisories

Past security advisories are published as [GitHub Security Advisories](https://github.com/openethereum/openethereum/security/advisories) in this repository.
